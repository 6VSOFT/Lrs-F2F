# 狼人杀 · 法官记录

线下面杀狼人杀的法官记录工具（PWA 网页应用）。玩家抽实体身份卡，法官主持夜间行动，用本应用按流程念口令、录入身份和标记玩家状态。

**在线使用：<https://6vsoft.github.io/Lrs-F2F/>**

## 功能

- **夜间流程**：打开即进入第 1 夜，按所选板子逐步显示口令，边走边录身份与目标；特殊身份录完后自动补上平民
- **自动判定**：刀口、解药、毒药、守护、摄梦、交换、查验结果、开枪状态等自动结算，天亮给出死讯
- **白天流程**：每天投票放逐 1 人（可选无人放逐），支持狼人自爆（含警长竞选中自爆）、骑士决斗、开枪
- **警长**：上警、退水、警下投票、当选或警徽流失，出局后移交或撕毁
- **记票（可选）**：记录谁投谁，警长 1.5 票，平票自动进 PK，再次平票无人放逐
- **开枪**：记录谁带走了谁，可更正；被毒杀、殉情、自爆等不可开枪时自动锁定
- **胜负提醒**：屠边规则，分出胜负自动提示
- **对局记录**：从第 1 夜起按顺序记录，列出 12 位玩家的身份与结局，可一键复制
- **玩家名字**、**撤销上一步**（刷新后仍可撤销最近 50 步）、**自动存档**（刷新后接着录）
- **历史对局**：新开一局时自动保存上一局，保留最近 20 局，可查看、复制、删除
- **隐藏身份**：座位、夜间面板、日志过程全部遮住，按住才显示，松手即遮
- **发言计时**：两个独立倒计时（默认 2:00 和 1:30，可换时长），最后 10 秒变色，到点震动加提示音（iPhone 只有声音）
- **夜间调暗、口令大字**：天黑自动调暗，可在菜单关闭
- **屏幕常亮**：主持时不熄屏，可在菜单关闭（需 HTTPS，部分浏览器不支持）
- **离线可用**：响应式布局，可安装到手机主屏幕

## 采用的规则

- **胜负（屠边）**：神职全体出局或平民全体出局，狼人获胜；狼人全体出局，好人获胜；同时达成按狼刀在先
- 女巫全程不可自救，同一夜不能同时用解药和毒药
- 预言家只验狼人或好人；混血儿属平民阵营，永远验为好人
- 白痴被放逐自动翻牌并视为出局，狼人无需追刀；夜间死亡不能翻牌
- 同守同救则死亡；守卫不能连续两夜守同一人；守护挡不住毒药
- 恶魔夜间免死
- 被毒杀不可开枪；自爆、殉情、死于梦中、被恐惧、被封印也不可开枪
- 狼人自爆直接入夜；狼美人、石像鬼、机械狼不能自爆；血月使徒自爆封印当夜神职技能

## 安装到手机

- **iPhone**：Safari 打开网址 → 分享 → 添加到主屏幕
- **Android**：Chrome 打开网址 → 菜单 → 安装应用

首次需联网打开一次，之后可离线使用。有新版时页面顶部会提示“有新版，点此更新”，点一下即可，对局保留。

## 数据与隐私

对局记录和玩家名字只保存在当前设备的浏览器里，不上传，也不在设备之间同步。清除浏览器数据会一并删除。

## 本地运行

无需构建，任意静态服务器即可：

```bash
python -m http.server 8123 --directory app
```

然后打开 <http://localhost:8123>。

## 测试

需要 Node 22 以上和 Edge 或 Chrome，没有其他依赖：

```bash
node tests/run.mjs
```

```bash
node tests/play.mjs --round 1 --boards std,mech --games 1
```

`run.mjs` 跑全部自动测试；`play.mjs` 用真实触控（round 1）或鼠标（round 2）打整局，并与独立计算比对，加 `--url` 可测在线版。推送到 main 后 GitHub 先跑这两套测试，全部通过才部署。
