# 狼人杀 · 法官记录

线下面杀狼人杀的法官记录工具（PWA 网页应用）。玩家抽实体身份卡，法官主持夜间行动，用本应用按流程念口令、录入身份和标记玩家状态。

**在线使用：<https://6vsoft.github.io/Lrs-F2F/>**

## 功能

- **夜间流程**：打开即进入第 1 夜，按所选板子逐步显示口令，边走边录身份与目标；特殊身份录完后自动补上平民
- **自动判定**：刀口、解药、毒药、守护、摄梦、交换、查验结果、开枪状态等自动结算，天亮给出死讯
- **白天流程**：每天投票放逐 1 人（可选无人放逐），支持骑士决斗、血月使徒自爆、开枪、警徽授予与移交提醒
- **胜负提醒**：屠边规则，分出胜负自动提示
- **对局记录**：从第 1 夜起按顺序记录，列出 12 位玩家的身份与结局，可一键复制
- **玩家名字**、**隐藏身份**、**撤销上一步**、**自动存档**（刷新后接着录）
- **离线可用**：响应式布局，可安装到手机主屏幕

## 采用的规则

- **胜负（屠边）**：神职全体出局或平民全体出局，狼人获胜；狼人全体出局，好人获胜；同时达成按狼刀在先
- 女巫全程不可自救，同一夜不能同时用解药和毒药
- 预言家只验狼人或好人；混血儿属平民阵营，永远验为好人
- 白痴被放逐自动翻牌并视为出局，狼人无需追刀；夜间死亡不能翻牌
- 同守同救则死亡；守卫不能连续两夜守同一人；守护挡不住毒药
- 恶魔夜间免死

## 安装到手机

- **iPhone**：Safari 打开网址 → 分享 → 添加到主屏幕
- **Android**：Chrome 打开网址 → 菜单 → 安装应用

首次需联网打开一次，之后可离线使用。有新版时，联网打开一次会在后台更新，再次打开生效。

## 数据与隐私

对局记录和玩家名字只保存在当前设备的浏览器里，不上传，也不在设备之间同步。清除浏览器数据会一并删除。撤销记录在刷新页面后失效。

## 本地运行

无需构建，任意静态服务器即可：

```bash
python -m http.server 8123 --directory app
```

然后打开 <http://localhost:8123>。
